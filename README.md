# 🚀 PTIT Programmer' Club - Wiki
## 1. Giới thiệu CLB
**PTIT Programmers' Club** là cộng đồng học thuật chuyên môn, nơi các thành viên biến kiến thức lý thuyết thành sản phẩm công nghệ thực tế.
## 2. Danh sách Ban
| Tên ban | Trưởng ban | Liên hệ |
|:-|:-|:-|
**Ban Chuyên Môn** | Hồ Anh Tuấn 1 | [tech.pc@ptit.edu.vn](mailto:tech.pc@ptit.edu.vn) |
**Ban Truyền Thông** | Hồ Anh Tuấn 2 | [media.pc@ptit.edu.vn](mailto:media.pc@ptit.edu.vn) |
## 3. Hướng dẫn Gia nhập
1. Clone repository của CLB
2. Tạo nhánh cá nhân theo mã sinh viên
3. Thêm thông tin vào danh sách thành viên và đẩy code lên hệ thống.
## 4. Checklist nhiệm vụ thành viên mới
- [x] Tham gia nhóm Zalo nội bộ và điểm danh thành công.
- [x] Đọc kỹ nội quy và quy chế hoạt động của CLB.
- [ ] Hoàn thành việc clone repository và tạo nhánh cá nhân trên GitHub.
- [ ] Đóng góp ít nhất 1 bài viết hoặc code mẫu lên Wiki chung.
- [ ] Tham gia buổi họp mặt định hướng cùng Ban Chuyên Môn.

⚠️**THÔNG BÁO QUAN TRỌNG**
